# Daleel (دليل) — Project-Based Learning Incubator

**Daleel** is an authentic secondary education project incubator platform that transforms classroom learning into an enterprise food science venture. Instead of fragmented lectures and arbitrary letter grades, students formulate, test, produce, and pitch real organic food bar startups.

---

## 🌟 Platform Highlights

### 1. Student Experience
- **Milestone Level Map**: 7 progressive incubator challenges from raw nutritional formulation to final investor pitch.
- **Socratic Mentor Desk**: Direct interactive inquiry guiding students through variable isolation, chemistry, and unit economics without giving away direct answers.
- **Field Professional Consultation**: Direct consultation channel with industry specialist **Dr. Wissam Sammouri** (*Biochemist & Food Science Advisor*).
- **Interactive Tooling**: Live batch formulation simulator, nutritional density calculator, cost curve modeling, packaging studio, and pitch deck builder.

### 2. Teacher Faculty Studio
- **Classroom Telemetry**: Real-time tracking of student focus, variable isolation rigor, and collaborative pod velocity.
- **Automated Interventions**: Proactive alerts when students encounter multi-variable test errors or stamina dips.
- **Faculty Copilot**: Instant pedagogical summaries and peer-pairing recommendations.

### 3. Parent Growth Ledger
- **Curriculum Transparency**: Clear competency metrics spanning Physical Science (NGSS), Linear Algebra (CCSS), and Cardiovascular Endurance (PE).
- **Narrative Progress**: Plain-language updates on what students mastered in the kitchen lab without punitive letter grading.

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **UI Library**: React 18, Tailwind CSS, Lucide React Icons
- **Data Visualization**: Recharts
- **Language**: TypeScript

## 🛠️ Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/noun-kris/daleel.git

# Navigate to project directory
cd daleel

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel (Access with a Link on Any Device)

1. Push this repository to your GitHub account (`noun-kris/daleel`).
2. Visit [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your `daleel` repository.
4. (Optional) Set the `GEMINI_API_KEY` environment variable if using external AI keys.
5. Click **"Deploy"**.
6. Within 60 seconds, you will receive a public URL (e.g. `https://daleel.vercel.app`) accessible from any smartphone, tablet, or PC worldwide!
